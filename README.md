# DSA Roadmap & Problem Tracker 🧠

An interactive Data Structures & Algorithms (DSA) preparation roadmap and problem tracker with direct LeetCode problem links, topic-wise categorizations, and progress persistence.

## Features
- **Visual Roadmap:** Interactive 3-column view (Topics → Subtopics → Questions).
- **Progress Tracking:** Saves checked problems locally in `localStorage`.
- **Direct Problem Links:** Instant jump to LeetCode questions.
- **Theme Support:** Dark / Light mode toggle.
- **Continuous Deployment:** Deployed on Vercel with automatic updates on every push.
